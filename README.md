🧠 Prime Number Logic

A prime number is a number greater than 1 that has exactly two factors: 1 and itself.

n = int(input("Enter a number: "))

if n < 2:
    print("Not Prime")
else:
    for i in range(2, n):
        if n % i == 0:
            print("Not Prime")
            break
    else:
        print("Prime")
